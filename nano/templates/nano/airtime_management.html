How to Add Airtime Products

Adding New Products

  • Product Name: Enter a descriptive name (e.g., "Vodacom R50 Airtime")
  • Network: Select the mobile network provider
  • Type: Choose between Airtime, Data, SMS Bundle, or Combo
  • Value: Enter the face value in Rands (what customer gets)
  • Selling Price: Enter your selling price (what customer pays)
  • Description: Optional - add product details
  • Initial Stock: Set starting inventory quantity

Managing Stock

  • Select Product: Choose from existing products
  • Quantity to Add: Enter amount to increase stock
  • Current Stock: Shows available inventory for each product

Pro Tips

  • Set selling price higher than face value for profit margin
  • Keep adequate stock levels to avoid sales interruptions
  • Monitor sales trends to optimize inventory
  • Use clear, consistent product naming conventions

Security & Permissions

  • Only Managers, Admins, and Superusers can add airtime products
  • Cashiers must request approval for new products through the request system
  • NEW: Cashiers can now sell airtime immediately without manager approval for urgent purchases!
  • Cashiers can customize airtime amounts using the quick sell feature
