Airtime Management

How to Add Airtime Products
Adding New Products
  1. Product Name: Enter a descriptive name (e.g., "Vodacom R50 Airtime")
  2. Network: Select the mobile network provider
  3. Type: Choose between Airtime, Data, SMS Bundle, or Combo
  4. Value: Enter the face value in Rands (what customer gets)
  5. Selling Price: Enter your selling price (what customer pays)
  6. Description: Optional - add product details
  7. Initial Stock: Set starting inventory quantity
Managing Stock
  1. Select Product: Choose from existing products
  2. Quantity to Add: Enter amount to increase stock
  3. Current Stock: Shows available inventory for each product
Pro Tips
  • Set selling price higher than face value for profit margin
  • Keep adequate stock levels to avoid sales interruptions
  • Monitor sales trends to optimize inventory
  • Use clear, consistent product naming conventions
Security & Permissions

Only Managers, Admins, and Superusers can add airtime products. Cashiers must request approval for new products through the request system.

Note: All airtime sales by cashiers require manager approval before completion.
